# HTTP-заголовок `flclashz-zapret`

Управление Zapret в FlClashZ для Windows через HTTP-заголовок ответа подписки (например, Remnawave).

## Синтаксис

```http
flclashz-zapret: autostart,mode:fullbypass,autofallback,autotune,tunemode:fast,tuneonfail
```

Значения разделяются запятыми. Регистр и пробелы вокруг элементов не важны.
Четыре флага передаются без значения: наличие включает функцию, отсутствие выключает.
Для двух параметров используется двоеточие. Неизвестные элементы и некорректные значения режимов игнорируются; при повторении режима применяется последнее корректное значение.

| Значение | Допустимые значения | Поведение |
|---|---|---|
| `autostart` | флаг | Запуск Zapret при обычном старте Mihomo. Отсутствие не запрещает ручной запуск или восстановление ранее работавшего процесса. |
| `mode:...` | `strictsplit`, `fullbypass` | STRICT SPLIT или FULL BYPASS. Если стратегия не поддерживает разделение, используется FULL BYPASS. Если параметр отсутствует, используется личная настройка. |
| `autofallback` | флаг | После трёх последовательных неуспешных проверок попытка применить другую подтверждённую стратегию. |
| `autotune` | флаг | Однократный автоматический подбор при отсутствии подтверждённой совместимой стратегии и трёх неуспешных проверках после запуска. |
| `tunemode:...` | `veryfast`, `fast`, `full` | Режим автоматического подбора. По умолчанию `fast`. Ручной подбор остаётся доступен. |
| `tuneonfail` | флаг | Повторный автоматический подбор после трёх неуспешных проверок, если подходящая резервная стратегия отсутствует или не восстановила доступность. |

### Режимы автоподбора

- `veryfast` — предварительный отбор, одна контрольная проверка, досрочное завершение при результате 6/6.
- `fast` — предварительный отбор и две контрольные проверки финалистов.
- `full` — полный перебор доступных стратегий, две контрольные проверки.

## Примеры

Только совместный запуск и FULL BYPASS:

```http
flclashz-zapret: autostart,mode:fullbypass
```

Автоподбор и восстановление:

```http
flclashz-zapret: autostart,mode:strictsplit,autofallback,autotune,tunemode:veryfast,tuneonfail
```

Все четыре флага выключены, режим остаётся личным:

```http
flclashz-zapret:
```

## Правила применения

- Заголовок читается при загрузке/обновлении подписки и применяется только к выбранному профилю на Windows.
- Если заголовка нет, сохраняется личное поведение клиента. Пустой заголовок отключает четыре флага, если HTTP-сервер и промежуточные прокси действительно передают его клиенту. При переключении на профиль без заголовка личные настройки восстанавливаются.
- Пока профиль управляет флагами, соответствующие переключатели autostart и autofallback недоступны для изменения; явный mode также управляется профилем.
- Автоподбор работает только при запущенном Zapret и доступном ядре, после завершения применения профиля. Используются существующие проверки YouTube и Discord по DIRECT. Неполные проверки не учитываются.
- Между автоматическими попытками восстановления действует пауза не менее пяти минут. Прерванный подбор не применяет новый результат. Без подтверждённого результата прежняя стратегия сохраняется.
- Для изменения режима у работающего Zapret используется существующий безопасный механизм перезапуска.
- Заголовок не содержит команд, URL для скачивания исполняемых файлов, BAT/CMD/Lua или произвольных параметров Helper. Защита инфраструктуры Mihomo и DNS сохраняется.
- Старые заголовки `flclashx-*` не меняются.
